Schadenmeldung Edge Unternehmen V14

Diese Version ist speziell fuer Microsoft Edge auf verwalteten iPads ausgelegt.

Beim Start wird automatisch geprueft:
1. localStorage fuer Namen, Einstellungen und Auftraege
2. IndexedDB fuer Fotos in der Schadenmeldung

Ergebnis wird oben in der App angezeigt:
- Gruen: dauerhafte Speicherung verfuegbar
- Gelb: Auftraege/Namen dauerhaft, Fotos nur Sitzung
- Rot: Unternehmensrichtlinie blockiert lokalen Speicher; Sitzungsmodus

Die App benoetigt Safari nicht fuer den normalen Betrieb.
