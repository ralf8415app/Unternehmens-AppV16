Komplette App-Anleitung – Notdienst Asyl

Firmen-Geräte: Funktionen können durch Unternehmensrichtlinien eingeschränkt sein. Namen und Einsätze werden nur lokal gespeichert, wenn Edge dies auf dem Gerät erlaubt.

1. Öffnen / Home-Bildschirm / Windows-App

iPad/iPhone Edge: App in Edge öffnen und über Teilen/Browsermenü „Zum Home-Bildschirm“ wählen, sofern angeboten. Fehlt die Option, als Edge-Favorit verwenden. Windows Edge: (…) → Apps → Diese Website als App installieren bzw. das Installationssymbol in der Adressleiste verwenden.

2. Mitarbeiter lokal anlegen

Name und Rolle im Bereich Mitarbeiter eingeben und lokal speichern. Es stehen keine festen Mitarbeiternamen im Server-Code.

3. Einsatz erfassen

KW, Datum, Uhrzeit von/bis, Mitarbeiter, Melder, Objekt/Straße und Schadensmeldung ausfüllen. Stunden werden automatisch berechnet. Vorhandene Textbausteine können eingefügt und anschließend angepasst werden.

4. Eintrag speichern

„Eintrag speichern“ speichert den Einsatz lokal und zeigt ihn in der Tabelle. Bei blockiertem lokalen Speicher bleiben Daten nur während der aktuellen Sitzung erhalten.

5. XLSX / CSV

„Echte XLSX erstellen“ erzeugt eine Excel-Datei. „CSV erstellen“ erzeugt eine einfache Tabellen-Datei. Speichern oder Teilen hängt von den Freigaben des Geräts und der Unternehmensrichtlinie ab.

6. Drucken / PDF

„Drucken/PDF“ öffnet die System-Druckfunktion. Dort kann – sofern vom Gerät unterstützt – auch als PDF gespeichert werden.

7. Datensicherung

„Datensicherung erstellen“ sichert ausschließlich die Notdienst-Daten und die lokal angelegten Notdienst-Mitarbeiter. Die Schadensmeldungs-App wird nicht mitgesichert. Sicherungsdateien geschützt und nur in freigegebenen Unternehmensspeichern ablegen.

8. Wiederherstellen / Versionswechsel

Vor einem Update ein Backup erstellen. In der neuen Version „Datensicherung wiederherstellen“ wählen und nur eine passende Notdienst-Sicherung verwenden. Vorhandene lokale Daten können beim Import ersetzt werden.

9. Schaden beauftragen

„Schaden beauftragen“ übergibt die aktuellen Einsatzangaben an die getrennte Schaden- und Auftragsmeldung. Dort die übernommenen Angaben kontrollieren und fehlende Pflichtfelder ergänzen.

10. Bearbeiten / Löschen

Gespeicherte Einsätze können einzeln bearbeitet oder gelöscht werden. „Alle Einträge löschen“ entfernt sämtliche Notdienst-Einträge auf diesem Gerät.

11. Offline / Datenschutz

Nach einem vollständigen Online-Laden werden Programmdateien für Offline-Nutzung zwischengespeichert. Erfasste Nutzdaten werden nicht automatisch an den Hosting-Server gesendet. Hosting, E-Mail, Teilen oder externe Speicherung können jedoch technische bzw. bewusst ausgewählte Daten an die jeweiligen Dienste übertragen.

Complete App Guide – Emergency Duty

Managed company devices: Features may be restricted by company policy. Names and duty records are stored persistently only if Edge storage is permitted on the device.

1. Open / Home Screen / Windows app

iPad/iPhone Edge: Open the app in Edge and use Share/browser menu → “Add to Home Screen” if available. Otherwise use an Edge favorite. Windows Edge: (…) → Apps → Install this site as an app, or use the install icon in the address bar.

2. Add employee locally

Enter name and role in the employee section and save locally. Employee names are not hard-coded in the server files.

3. Record duty call

Enter calendar week, date, start/end time, employee, reporter, property/street and incident description. Hours are calculated automatically. Prepared text blocks can be inserted and edited.

4. Save entry

“Eintrag speichern” stores the duty record locally and shows it in the table. If local storage is blocked, data remains only for the current session.

5. XLSX / CSV

“Echte XLSX erstellen” creates an Excel file; “CSV erstellen” creates a simple table file. Saving and sharing depend on device/company permissions.

6. Print / PDF

“Drucken/PDF” opens the system print function. Where supported, the result can also be saved as PDF.

7. Backup

“Datensicherung erstellen” backs up only Notdienst records and locally created Notdienst employees. Damage-app data is not included. Store backups only in an approved protected company location.

8. Restore / version change

Create a backup before updating. In the new version select “Datensicherung wiederherstellen” and use only a matching Notdienst backup. Existing local data may be replaced.

9. Create damage order

“Schaden beauftragen” transfers the current duty information to the separate damage/work-order app. Review transferred information and complete missing mandatory fields.

10. Edit / delete

Stored duty records can be edited or deleted individually. “Alle Einträge löschen” removes all Notdienst records on this device.

11. Offline / privacy

After one complete online load, program files are cached for offline use. Entered user data is not automatically sent to the hosting server. Hosting, email, sharing and external storage may still process technical data or data deliberately selected by the user.
